# React Native Guide

## React Native Architecture
The new architecture in React Native introduces the Fabric rendering system and TurboModules. These improvements drastically enhance performance by minimizing the overhead of the asynchronous bridge communication between JavaScript and native iOS/Android code.

## React Native Navigation
React Navigation is the standard community library for routing and navigation in React Native mobile apps. Use `Stack Navigator` for linear navigation flows and `Tab Navigator` for the main dashboard sections.

## State Management
For state management in React Native, you can use built-in hooks like `useState` and `useReducer` for local state, or external libraries like Redux, Zustand, or Jotai for complex global state.
